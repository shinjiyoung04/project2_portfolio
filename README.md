# Shin Ji Young — Software Engineer Portfolio

채용 제출용 정적 포트폴리오 사이트입니다. HTML/CSS/JavaScript만 사용하므로 빌드 및 별도의 백엔드 서버 없이 배포할 수 있습니다.

## 로컬 확인

`index.html` 파일을 브라우저로 열거나, 프로젝트 폴더에서 다음을 실행합니다.

```bash
python -m http.server 8080
```

브라우저에서 `http://localhost:8080`에 접속합니다.

## GitHub Pages 배포

1. 개인 GitHub 계정에서 **공개(Public)** 저장소를 새로 만듭니다. 이름 예시: `portfolio`.
2. 이 폴더의 파일과 `assets` 폴더를 저장소 루트에 업로드합니다. `index.html`은 루트에 있어야 합니다.
3. GitHub 저장소의 **Settings → Pages → Build and deployment → Source: Deploy from a branch**를 선택합니다.
4. `main` 브랜치, `/(root)`를 선택하고 Save를 누릅니다.
5. 배포 후 `https://shinjiyoung04.github.io/portfolio/` 형식의 주소에서 확인합니다. 실제 주소는 저장소 이름에 따라 다릅니다.

## Netlify 배포

Netlify에서 새 사이트를 추가하고 이 폴더를 드래그 앤 드롭하면 별도의 빌드 설정 없이 정적 사이트를 배포할 수 있습니다.

## 반드시 확인할 항목

- 사이트에 표시된 프로젝트 개인 기여는 제공된 팀 보고서와 발표자료의 역할 구분에 기초합니다. 최종 면접 전 실제 수행 업무와 일치하는지 검토해 주세요.
- 이력서에 기재된 학력·자격증 상태가 변경되었다면 수정합니다. `정보처리기사`는 **필기 합격**으로만 표시합니다.
- 메일 주소는 첨부 이력서에서 마스킹되어 있어 사이트에 넣지 않았습니다. 공개용 메일이 필요하면 contact 섹션에 직접 추가하세요.
- 시연 영상(약 17MB)이 포함되어 배포 저장소 용량 및 트래픽을 사용합니다. 필요하면 YouTube 비공개 링크 대신 '일부 공개' 링크로 교체할 수 있습니다.
- 개인 얼굴 사진은 웹사이트에 포함하지 않았습니다.
- HTTPS 및 도메인 주소는 배포 플랫폼에서 설정합니다. 사이트 자체는 서버 저장, 로그인, 개인정보 수집 기능이 없습니다.

## 디렉터리

- `index.html`: 본문 콘텐츠, SEO 정보
- `styles.css`: 반응형 스타일
- `script.js`: 모바일 메뉴, 이미지 확대 보기, 스크롤 진행바
- `assets/`: 사용자가 제공한 실제 화면 및 시연 영상
